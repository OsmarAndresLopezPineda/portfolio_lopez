# Portafolio perosnal.

Este es un proyecto de desarrollo web donde plasmo todos los conocimientos adquiridos durante mi bootcamp de TripleTen, utilizando diseño web adaptativo, metodologia BEM, Flexbox, Gridbox, y muchas otras herramientas que adquiri en el curso.

## Características del proyecto

# Lenguajes

- HTML5
- CSS
- JavaScript

# Metodologia

- Programacion Orientada a Objetos
- Metodologia BEM
- Flexbox
- Gridbox
- Diseño Web Adaptativo (Telefono, Tablet, Escritorio)

# Diseño

- Implementacion de fuentes externas
- Barra de navegacion (Nav)
- Objetos Embebidos
